### 1. Token 统计功能

**文件**: `js/modules/patent-detail-newtab/chat.js`

**新增方法**:
- `updateTokenCount()` - 更新 Token 计数器显示

**HTML 元素**:
- `newtab_chat_token_count` - Token 计数显示元素

**Token 计算规则**:
```javascript
estimateTokens: function(text) {
    if (!text) return 0;
    let chineseChars = 0;
    let otherChars = 0;
    for (let i = 0; i < text.length; i++) {
        const char = text[i];
        if (/[\u4e00-\u9fa5]/.test(char)) {
            chineseChars++;
        } else {
            otherChars++;
        }
    }
    return Math.ceil(chineseChars / 1.5) + Math.ceil(otherChars / 4);
}
```

**显示位置**: 输入框右下方，绝对定位

**更新时机**:
- 打开问一问弹窗时初始化
- 输入框内容变化时实时更新
- 点击快捷问题按钮后立即更新

### 3. 文本转义处理

**新增方法**:
- `escapeHtmlAdvanced(text)` - 高级 HTML 转义

**转义规则**:
```javascript
escapeHtmlAdvanced: function(text) {
    if (!text) return '';
    return String(text)
        .replace(/&/g, '&amp;')
        .replace(/</g, '&lt;')
        .replace(/>/g, '&gt;')
        .replace(/"/g, '&quot;')
        .replace(/'/g, '&#039;')
        .replace(/\n/g, '<br>')
        .replace(/\r/g, '')
        .replace(/\t/g, '&nbsp;&nbsp;&nbsp;&nbsp;');
}
```

**应用场景**:
- 用户消息显示（`sendMessage`）
- 历史消息恢复（`restoreHistory`）
- 错误消息显示（`sendMessage` catch 块）

**安全性保障**:
- 防止 XSS 攻击
- 正确处理引号，避免 HTML 结构破坏
- 保留换行和缩进格式
