🧪 新标签页问一问功能增强测试

测试概述

本测试页面用于验证新标签页专利详情中"问一问"功能的增强特性：

  • Token 统计功能
  • 快捷问题按钮（全部内容添加）
  • 文本转义处理
  • 与弹窗详情功能的一致性

1. Token 统计功能 待测试

测试步骤：
  1. 在功能六中查询任意专利
  2. 点击"新标签页打开"按钮
  3. 在新标签页中点击顶部工具栏的"问一问"按钮
  4. 在输入框中输入文字
  5. 观察 Token 计数器是否实时更新
预期结果：
  • 输入框右下方显示 Token 计数器
  • 输入文字时 Token 数量实时更新
  • Token 计算规则：中文汉字每 1.5 个字符=1 Token，其他字符每 4 个=1 Token
  • 计数器格式："X Tokens"
Token 计算示例：

输入：这个专利的核心技术是什么？

字符数：13 个汉字 + 1 个标点 = 14 字符

估算 Token 数：10 Tokens (13/1.5 ≈ 9 + 1/4 = 1 → 10 Tokens)
