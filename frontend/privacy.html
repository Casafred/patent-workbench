隐私政策

📅 最后更新日期：2026年3月24日

🔒 核心承诺：我们不存储您上传的专利数据。所有数据仅在分析过程中临时使用，处理完成后立即删除。

1. 信息收集

我们收集以下类型的信息：

1.1 账号信息

  • 用户名和密码（加密存储）
  • 登录IP地址（用于安全验证）
  • 登录时间记录

1.2 使用数据

  • 功能使用记录（用于改进服务）
  • 错误日志（用于故障排查）

1.3 不收集的信息

  • ❌ 您上传的专利文档内容
  • ❌ 分析结果数据
  • ❌ 个人敏感信息
  • ❌ 第三方账号信息

2. 信息使用

我们使用收集的信息用于：

  • 提供和维护服务
  • 验证用户身份
  • 改进产品功能
  • 排查技术故障
  • 防止欺诈和滥用

3. 数据处理说明

3.1 临时处理流程

当您上传专利文档进行分析时：

📤 上传文件 → ⚡ 内存处理 → 📊 返回结果 → 🗑️ 立即删除
  • 文件被临时存储在服务器内存中
  • 分析完成后立即从内存中删除
  • 不会保存到硬盘或数据库
  • 不会备份或归档

3.2 本地存储

我们使用浏览器本地存储（LocalStorage）保存：

  • 用户偏好设置
  • 界面配置
  • 临时会话数据
  • 用户缓存数据（仅存储在用户本地浏览器）

这些数据仅存储在您的浏览器中，我们无法访问。

4. 数据安全

我们采取以下措施保护您的信息安全：

  • ✅ 使用 HTTPS 加密传输
  • ✅ 密码采用加密算法存储
  • ✅ 限制数据访问权限
  • ✅ 定期安全审计
  • ✅ 及时更新安全补丁

5. 信息共享

我们不会与任何第三方共享您的个人信息，除非：

  • 获得您的明确同意
  • 法律法规要求
  • 保护我们的合法权益

6. Cookie 使用

我们使用 Cookie 用于：

  • 保持登录状态
  • 记住用户偏好
  • 分析网站使用情况

您可以通过浏览器设置拒绝 Cookie，但这可能影响部分功能的使用。

7.2 阿里云百炼

  • 数据处理：您的数据将通过API发送到阿里云百炼进行处理
  • 责任说明：阿里云百炼服务合规性由阿里云负责
  • 隐私政策：https://help.aliyun.com/document_detail/428765.html

7.3 EPO OPS（欧洲专利局）

  • 用途：全球专利数据查询

  • 责任说明：服务可用性由欧洲专利局负责

7.4 Google Patents

  • 用途：专利数据查询
  • 使用方式：通过公开API查询专利信息
  • 数据来源：公开数据源
⚠️ 重要说明：
  • 我们不存储您的第三方服务API Key
  • 第三方服务的使用完全由您自己控制
  • 第三方服务有各自的隐私政策和服务条款
  • 我们不对第三方服务的行为负责

8. 数据保留

  • 账号信息：账号存续期间
  • 登录日志：保留 30 天
  • 上传文件：不保留（处理后立即删除）
  • 分析结果：不保留（由用户自行导出）
  • 用户缓存：存储在用户本地浏览器，用户可自行清除

9. 您的权利

您有权：

  • 查询您的账号信息
  • 修改您的账号信息
  • 删除您的账号
  • 导出您的数据
  • 拒绝特定数据处理
  • 清除本地缓存数据

9.1 用户数据管理功能

本平台提供以下用户数据管理功能，帮助您更好地控制自己的数据：

  • 缓存数据导出：您可以将本地存储的所有缓存数据导出为JSON文件进行备份保存
  • 缓存数据导入：您可以导入之前导出的缓存数据文件，恢复您的工作状态
  • 缓存数据清除：您可以一键清除本地存储的所有缓存数据
  • 对话历史管理：您可以查看、导出和删除对话历史记录
  • API Key管理：您可以随时更新或删除您配置的第三方服务API Key
⚠️ 重要提示：本地缓存数据仅存储在您的浏览器中，清除浏览器数据或更换设备后将无法恢复。建议您定期使用导出功能备份重要数据。

10. 儿童隐私

本服务不面向 14 岁以下儿童。我们不会故意收集儿童的个人信息。如发现误收集，我们将立即删除。

11. 政策更新

我们可能不时更新本隐私政策。更新后的政策将在网站上公布，并注明更新日期。继续使用服务即表示您接受更新后的政策。
