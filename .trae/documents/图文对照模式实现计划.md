## 实现图文对照模式

### 1. 添加按钮（在双栏对照按钮旁边）
在 `patentDetailNewTab.js` 第868行后添加"图文对照"按钮，样式与双栏按钮一致。

### 2. 创建图文对照模式函数
新增 `toggleImageTextMode()` 函数，实现：
- **左侧**：可滚动的专利详情内容（复用双栏模式的左侧逻辑）
- **右侧**：嵌入式附图查看器
  - 主图显示区域
  - 缩放按钮（放大/缩小/重置）
  - 旋转按钮（左转/右转）
  - 智能标记按钮
  - 前后张切换箭头
  - 底部缩略图导航条

### 3. 布局设计
```
┌─────────────────────────────────────────────────────────┐
│  [双栏对照] [图文对照] [PDF原文] [Google Patents]        │
├──────────────────────┬──────────────────────────────────┤
│                      │                                  │
│   专利详情内容        │        附图查看器                │
│   (可滚动)           │   ┌──────────────────────┐       │
│                      │   │  [缩放] [旋转] [标记] │       │
│   - 基本信息         │   │                      │       │
│   - 摘要             │   │      主图显示         │       │
│   - 权利要求         │   │                      │       │
│   - 说明书           │   └──────────────────────┘       │
│   - 附图             │   [缩略图缩略图缩略图...]         │
│   - ...              │                                  │
└──────────────────────┴──────────────────────────────────┘
```

### 4. 模式互斥处理
- 开启图文对照模式时，自动关闭双栏对照模式
- 开启双栏对照模式时，自动关闭图文对照模式
