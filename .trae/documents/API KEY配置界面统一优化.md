## 问题分析

当前界面存在以下问题：
1. **切换式设计**：选择智谱AI时只显示智谱配置，选择阿里云时只显示阿里云配置
2. **样式不统一**：阿里云配置缺少"显示/隐藏"按钮
3. **用户体验差**：无法同时配置多个平台

## 优化方案

### 1. 修改HTML结构 (`frontend/components/header.html`)
- 移除服务商选择器的切换逻辑
- 同时显示智谱AI和阿里云百炼两个配置区域
- 为阿里云配置添加"显示/隐藏"按钮，与智谱样式统一
- 保留服务商选择器作为"默认服务商"选择（决定默认使用哪个平台的模型）

### 2. 修改JS逻辑 (`js/core/api.js`)
- 修改 `updateProviderUI()` 函数，让两个配置区域始终显示
- 添加阿里云API Key的"显示/隐藏"功能
- 保存时同时保存两个平台的API Key

### 3. 确保功能正常
- 已有API Key的平台模型可以正常使用
- 未配置API Key的平台模型不可用（自动过滤）
- 用户可以随时补充配置任一平台
