## 设计方案：固定悬浮侧边导航栏

### 设计理念
采用类似 **Linear、Notion、Vercel** 的现代侧边栏设计，科技感、简约、美观。

### 核心效果
1. **固定左侧悬浮** - 侧边栏固定在屏幕左侧，不随页面滚动
2. **玻璃拟态效果** - 半透明模糊背景，增加科技感和层次感
3. **SVG图标+文字** - 每个功能项配有简洁SVG图标，悬浮时显示完整文字
4. **激活状态** - 当前选中的功能项有明显的渐变背景高亮
5. **悬浮动画** - 鼠标悬浮时轻微放大、发光效果
6. **可收起/展开** - 点击按钮可收起为图标模式，节省空间
7. **响应式** - 移动端自动隐藏，点击按钮展开

### 视觉预览
```
┌──────┐
│ ☰   │  ← 收起/展开按钮
├──────┤
│ ◉   │  AI智能体对话 (选中状态 - 高亮)
│ ≡   │  文本批量智能分析
│ 📁  │  本地数据表管理
│ ⚖   │  权利要求智能比对
│ 🔍  │  批量专利检索与解读
│ 📋  │  独从权识别与可视化
│ 🖼   │  专利附图智能标记
│ 📄  │  文档OCR与智能分析
│ 📚  │  IPC分类智能查询
└──────┘
```

### SVG图标设计
- AI智能体对话：聊天气泡图标
- 文本批量分析：列表/表格图标
- 本地数据管理：文件夹图标
- 权利要求比对：天平/对比图标
- 专利检索：搜索图标
- 独从权识别：层级/树形图标
- 附图标记：图片/标注图标
- OCR分析：文档/扫描图标
- IPC查询：分类/书架图标
