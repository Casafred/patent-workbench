## 修复方案

### 问题根因
`text_segment_extractor.py`中的`_build_marker_pattern`方法在`markers`为空集合时会生成无效正则表达式，导致服务器崩溃返回非JSON响应。

### 修复内容
只需在`text_segment_extractor.py`的`_build_marker_pattern`方法中添加空markers检查：

```python
def _build_marker_pattern(self, markers: Set[str]) -> re.Pattern:
    # 添加空检查
    if not markers:
        return re.compile(r'(?!a)a')  # 永不匹配的正则
    
    # 原有逻辑...
```

### 不修改的部分
- 非分阶段API：保持原始逻辑（直接处理完整说明书）
- 分阶段API：保持原始逻辑（有回退机制会重新提取）
- 前端：保持原始逻辑

这样可以最小化改动，只修复崩溃问题。
