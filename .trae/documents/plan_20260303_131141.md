## 修复方案

### 问题分析
1. **正则表达式太严格**：当前模式要求标记后面必须有分隔符，但说明书中的标记可能直接跟在部件名称后面（如"外壳10"）
2. **OCR结果包含干扰项**：如"FIG. 2"、"A"等，这些在说明书中可能匹配不到
3. **分句可能过于细碎**：需要确保取完整的前后句子

### 修复内容

**1. 改进正则表达式匹配模式**
```python
# 更宽松的匹配：标记前后可以是任意非数字字符或边界
pattern = rf'(?<![0-9A-Za-z])({marker_group})(?![0-9A-Za-z])'
```
这能匹配：
- "外壳10" ✓
- "10. 外壳" ✓
- "（10）" ✓
- "第10实施例" ✓

**2. 过滤OCR结果**
```python
# 过滤掉图号引用和单个字母
filtered_markers = {m for m in ocr_markers 
                    if not m.startswith('FIG') 
                    and not m.startswith('图')
                    and (len(m) > 1 or m.isdigit())}
```

**3. 增加上下文句子数**
- 默认 `context_sentences` 从1改为2，确保取足够的前后句子

**4. 添加调试日志**
- 打印匹配到的句子，方便诊断
