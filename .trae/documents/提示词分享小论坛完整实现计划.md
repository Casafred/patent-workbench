## 提示词分享小论坛 - 完整实现计划

### 一、数据库设计（PostgreSQL）

创建以下数据表：
- `prompt_categories` - 提示词分类表
- `prompt_tags` - 标签表
- `prompts` - 提示词主表（含目标功能字段）
- `prompt_tag_relations` - 提示词-标签关联表
- `prompt_comments` - 评论表
- `prompt_likes` - 点赞表
- `prompt_favorites` - 收藏表
- `prompt_moderation_logs` - 审核日志表

### 二、后端 API 开发

**Phase 1 - 基础CRUD**
- `GET/POST /api/prompts` - 提示词列表/发布
- `GET/PUT/DELETE /api/prompts/:id` - 详情/编辑/删除

**Phase 2 - 互动功能**
- `POST/DELETE /api/prompts/:id/like` - 点赞
- `POST/DELETE /api/prompts/:id/favorite` - 收藏
- `POST /api/prompts/:id/import` - 导入（记录次数）
- `GET/POST /api/prompts/:id/comments` - 评论

**Phase 3 - 分类搜索**
- `GET /api/prompts/categories` - 分类列表
- `GET /api/prompts/tags` - 热门标签
- `GET /api/prompts/user/mine` - 我的发布
- `GET /api/prompts/user/favorites` - 我的收藏

**Phase 4 - 审核管理**
- `GET /api/prompts/moderation/pending` - 待审核列表
- `POST /api/prompts/moderation/approve/:type/:id` - 通过
- `POST /api/prompts/moderation/reject/:type/:id` - 拒绝

### 三、前端页面开发

**Phase 1 - 核心页面**
- 提示词广场入口按钮（导航栏）
- 提示词列表页（筛选、搜索、分页）
- 提示词详情页（内容展示、互动按钮）
- 发布提示词页（支持选择目标功能）

**Phase 2 - 用户中心**
- 我的发布页面
- 我的收藏页面

**Phase 3 - 管理功能**
- 审核管理面板（管理员）

### 四、功能联动开发

**Phase 1 - 导入功能**
- 论坛提示词 → 功能一格式转换
- 论坛提示词 → 功能五格式转换
- 一键导入按钮与交互

**Phase 2 - 快速发布**
- 功能一角色 → 分享到论坛
- 功能五模板 → 分享到论坛
- 自动填充发布表单

### 五、关键技术点

1. **统一提示词格式**：设计兼容所有功能的提示词数据结构
2. **格式转换层**：实现论坛格式与各功能格式的双向转换
3. **审核流程**：所有发布/评论需管理员审核
4. **权限控制**：浏览公开，操作需登录
