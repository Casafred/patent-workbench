## 设计方案：现代Pill Tabs导航

### 设计风格
采用类似 **shadcn/ui** 和 **Linear** 的现代设计风格，结合玻璃拟态效果。

### 核心效果
1. **Pill按钮** - 每个标签是独立的圆角胶囊按钮，间距8px
2. **滑动指示器** - 底部有一条平滑滑动的指示线，跟随选中标签
3. **玻璃拟态** - 半透明模糊背景效果
4. **微妙动画** - 悬浮时轻微上浮+阴影，选中时背景渐变
5. **横向滚动** - 支持横向滚动，带自定义滚动条

### 视觉预览
```
默认状态：
[AI智能体对话] [文本批量分析] [本地数据管理] ...
══════════════ (滑动指示器)

选中状态：
[AI智能体对话] ← 渐变背景+上浮
══════════════ (指示器对齐)
```
